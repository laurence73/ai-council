🚀 Quick Start

1

Install Dependencies

Clone the repo and install Python packages.

2

Set API Keys

Add your OpenAI and xAI keys as environment variables.

3

Run Reviews

Use the CLI to review files or enable watch mode.

Step 1: Install

# Clone the repository
git clone https://github.com/laurence73/ai-council.git
cd ai-council

# Install Python dependencies
pip install -r requirements.txt

Step 2: Configure API Keys

# PowerShell (permanent - restart terminal after)
[Environment]::SetEnvironmentVariable("OPENAI_API_KEY", "sk-...", "User")
[Environment]::SetEnvironmentVariable("XAI_API_KEY", "xai-...", "User")
Model Environment Variable Get API Key
GPT-4 OPENAI_API_KEY platform.openai.com/api-keys
Grok XAI_API_KEY console.x.ai
Gemini GOOGLE_API_KEY makersuite.google.com

Step 3: Test It

# Check which reviewers are active
python vscode-extension/ai_council.py status

# Review a file
python vscode-extension/ai_council.py review "path/to/your/code.cs"

# Force re-review (bypass cache)
python vscode-extension/ai_council.py review "path/to/your/code.cs" --force

💻 CLI Commands

Command Description
python vscode-extension/ai_council.py status Show active reviewers and pending queue
python vscode-extension/ai_council.py review <file> Review a file with all active models
python vscode-extension/ai_council.py review <file> --force Force re-review (ignore cache)
python vscode-extension/ai_council.py show <file> Show cached reviews for a file
python vscode-extension/ai_council.py queue <file> Queue file for background review
python vscode-extension/ai_council.py process Process pending review queue
python vscode-extension/ai_council.py watch --path <dir> Watch directory for file changes

🔗 Claude Code Integration

AI Council integrates with Claude Code in two ways:

⚡

Hooks (Auto-Queue)

Automatically queue files for review when Claude edits them

🔌

MCP Server

Let Claude query reviews directly in conversation

Option A: Auto-Queue via Hooks

Add to ~/.claude/settings.json. Set AI_COUNCIL_WORKSPACE to the same project folder you review from the VS Code extension - both write to <workspace>/.ai-council/reviews.db, so a queued file lands where the extension can actually see it:

{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "^(Edit|Write)$",
        "command": "python \"/absolute/path/to/your/ai-council/checkout/queue_review.py\" \"$TOOL_INPUT_file_path\"",
        "env": { "AI_COUNCIL_WORKSPACE": "C:/path/to/your/project" }
      }
    ]
  }
}
💡

How it works

Every time Claude uses Edit or Write tools, the file is added to that workspace's queue table. Run python vscode-extension/ai_council.py --db "<workspace>/.ai-council/reviews.db" process periodically to process the queue.

Option B: MCP Server (Query Reviews)

Add to ~/.claude/settings.json. AI_COUNCIL_WORKSPACE here too, for the same reason - it's how the server finds the workspace database the extension actually wrote to:

{
  "mcpServers": {
    "ai-council": {
      "command": "python",
      "args": ["/absolute/path/to/your/ai-council/checkout/mcp_server.py"],
      "env": {
        "AI_COUNCIL_WORKSPACE": "C:/path/to/your/project",
        "OPENAI_API_KEY": "sk-...",
        "XAI_API_KEY": "xai-..."
      }
    }
  }
}

Then Claude can call these MCP tools:

MCP Tool Purpose
mcp__ai-council__get_reviews Get cached reviews for a file
mcp__ai-council__request_review Request immediate review
mcp__ai-council__get_consensus Get consensus summary
mcp__ai-council__council_status Check active reviewers

📊 Understanding Reviews

Each AI model returns a structured review with:

Field Description
Quality Score 1-10 rating of overall code quality
Summary Brief assessment of the code
Issues List of problems found with severity, line, and recommendation

Severity Levels

Severity Meaning Action
CRITICAL Security vulnerability, data loss risk Fix immediately
HIGH Bug, logic error, significant issue Fix before merge
MEDIUM Code smell, maintainability concern Should fix
LOW Style issue, minor improvement Consider fixing
INFO Suggestion, observation Optional
🎯

Consensus = Confidence

When multiple models flag the same issue, it's almost certainly a real problem. Unique insights from a single model are worth investigating but may be false positives.

⚠️

Cost Control Tips

Reviews are cached by file hash - re-reviewing unchanged files is free. Use --force only when needed. Consider disabling expensive models for routine reviews.
