Multi-Model Code Review Architecture

📋 Overview

AI Council runs parallel code reviews using multiple AI models, then synthesizes their findings to identify consensus issues (high confidence) and unique insights from each model.

🔄 Complete Review Flow

1

📁 File Input

User provides file path via CLI or Claude Code skill

/ai-council src/MyComponent.razor --html
2

🔍 Cache Check

Compute file hash (SHA-256) and check SQLite cache for existing review

If cached and not --force: return cached result instantly

3

📖 File Reading

Read file contents, detect language from extension

For large files (Grok): chunk at class/function boundaries (15KB max)

4

⚡ Parallel Review Dispatch

Concurrent Execution (asyncio.gather)

🧠 GPT-4

OpenAI API

⚡ Grok

xAI API (chunked)

🔮 Claude

Anthropic API

💎 Gemini

Google API (optional)

Each model receives identical prompt requesting structured JSON output

5

📊 Response Collection

Each model returns JSON with:

{ "issues": [ { "severity": "HIGH", "line": 42, "description": "SQL injection vulnerability", "recommendation": "Use parameterized queries", "confidence": 95 } ], "summary": "Overall assessment...", "quality_score": 7 }
6

🎯 Consensus Detection

Compare issues across models to find agreement:

  • Same line number (±5 lines tolerance)
  • Similar severity level
  • Overlapping keywords in description

Issues flagged by 2+ models = High Confidence

7

💾 Cache Storage

Store results in SQLite with file hash as key

Future reviews of unchanged files return instantly

8

📄 Output Generation

Generate output based on flags:

Flag Output
--html Beautiful HTML report with logo, scores, issues
(default) JSON to stdout + terminal summary

⚙️ Environment Setup

Required API keys in C:\AI COUNCIL\.env:

OPENAI_API_KEY=sk-proj-... # GPT-4 (required) XAI_API_KEY=xai-... # Grok (required) ANTHROPIC_API_KEY=sk-ant-... # Claude (required) GOOGLE_API_KEY=... # Gemini (optional)

🚀 Usage Examples

Command Models Used
python ai_council.py review file.py GPT-4 + Grok + Claude (3 models)
python ai_council.py review file.py --gemini GPT-4 + Grok + Claude + Gemini (4 models)
python ai_council.py review file.py --html 3 models + HTML report
python ai_council.py review file.py --force 3 models, bypass cache
